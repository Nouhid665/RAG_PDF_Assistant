RAG PDF Assistant

A Retrieval Augmented Generation (RAG) application that allows users to upload PDFs and ask questions about them.

 Features

- PDF question answering
- Vector search using ChromaDB
- Ollama LLM integration
- Streamlit UI

 Tech Stack

- Python
- LangChain
- ChromaDB
- Ollama
- Streamlit

 Run locally

pip install -r requirements.txt

streamlit run main.py
